# Frontend

Interface web responsiva para gerenciamento de benefícios.

## Como rodar

```bash
cd frontend
npm run start
```

A aplicação será servida em `http://localhost:4200` e consumirá o backend em `http://localhost:9090`.

## Funcionalidades

- Listagem de benefícios
- Criação de benefício
- Edição de benefício
- Exclusão de benefício
- Transferência de saldo entre benefícios ativos
